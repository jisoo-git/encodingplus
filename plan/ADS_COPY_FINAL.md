## 광고 그룹 구조

검색하는 사람이 두 종류라서 그룹을 나눠야 함.

| | 그룹 1 — 디미고 인지층 | 그룹 2 — 특성화고·코딩 탐색층 |
|--|---|---|
| 검색어 예시 | 디미고 학원, 디미고 특강 | 특성화고 학원, 코딩 학원, IT 고등학교 |
| 상태 | 디미고 알고 학원 찾는 중 | 방향 탐색 중, 디미고 모를 수 있음 |
| 소재 방향 | 실적으로 확신 → 선착순 마감 | 디미고 소개 → 전문 학원 → 지금 특강 |

> 두 그룹 모두 네이버·구글 동일하게 적용. 플랫폼은 형식만 다름.

### 네이버 파워링크 (제목 15자 이내 · 설명 45자 이내)

| | |
|--|--|
| 제목 | 디미고 합격률 전국 1위 인코딩플러스 |

**소재 2 — 마감 긴박감형 (FOMO)**
> A/B 중 "지금 안 하면 손해"로 밀어붙이는 쪽

| | |
|--|--|
| 제목 | 디미고 특강 7/18 선착순 마감 |
